# Демонстрация на защите

1. Открыть README репозитория nureek2001/aiagentcheck и docs/SUBMISSION.md — там итоговый запуск и SHA оригинала.
2. Показать workflow команды: доверенный агент и неизменённый target скачиваются отдельно. В репозитории организаторов ничего не меняется.
3. Открыть настоящий запуск Actions и его артефакты. Показать код, количество нарушений и ID требований в журнале.
4. Открыть dashboard.html из комплекта либо локальную панель. Показать commit, все восемь статусов, одну находку с доказательствами и дополнительные замечания отдельно.
5. Объяснить: код 1 означает завершённую проверку с нарушениями; код 2 — неполный аудит. Красный job при коде 1 является ожидаемым результатом.
6. Показать защиту main в helpdesk-demo: Security merge gate обязателен, strict включён, правило действует для администратора. PR #1 был реально blocked без успешного check и закрыт без merge.
7. Показать описание подхода на двух страницах, метрики и ограничения. Разработка патчей — дополнительная функция; не применять её к официальному target.

## Что делает интерфейс

Панель показывает историю и внутренние события GitHub Checks: этап, обработанные части, время и usage. Для выбранного запуска отображаются только его данные. GitHub Actions работает без открытого браузера; локальная панель требует запущенного сервера. Сохранённый dashboard.html открывается без ключа и без API.

## Что не обещать

Нет гарантии обнаружения всех нарушений, отсутствия ложных срабатываний или полной замены эксперта. Проверка статическая: инфраструктурные права и сертификация не подтверждаются. Зелёные unit-тесты не доказывают безопасность Helpdesk. Синтетический benchmark не заменяет скрытую разметку организаторов. Delivery — демонстрационный шаг, настоящего развёртывания нет.

## Расходы

Просмотр отчётов бесплатен. Push и PR продукта могут запускать отдельные платные проверки. Для защиты используйте сохранённые артефакты; новый прогон запускайте осознанно. Итоговый официальный аудит выполнен через workflow_dispatch с закреплённым target SHA.
