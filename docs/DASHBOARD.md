# Панель проверок

Панель работает на компьютере команды и доступна только через loopback. Она не запускает платный
анализ при открытии или обновлении страницы. Обычный `scan` остаётся неинтерактивным CI-инструментом.

## Локальный запуск

```powershell
.\scripts\dashboard.ps1
# Открыть http://127.0.0.1:8765
```

Эквивалент:

```powershell
.venv/Scripts/python.exe -m kmg_agent dashboard --reports reports --repo targets/KMG-Digital-Hackathon
```

Панель показывает историю, обязательные и дополнительные находки, доказательства, статусы требований,
метрики и скачивание отчётов. Во время локального scan каждые 3 секунды читаются `progress.json` и
`checkpoint.json`. После завершения приоритет имеют итоговый отчёт или ошибка. Нет новых событий
более 5 минут — показывается неизвестное состояние, а не выдуманный прогресс.

## GitHub Actions

Для чтения запусков и загрузки артефактов панель использует существующую авторизацию GitHub
из Git Credential Manager. Альтернатива — добавить `GH_TOKEN` в локальный `.env`.
Fine-grained token ограничьте вашим репозиторием, правами Actions: read и Metadata: read.
Не вставляйте токен в интерфейс, URL или Git. Затем:

```powershell
.\scripts\dashboard.ps1 -GitHubRepo nureek2001/aiagentcheck
```

Панель раз в 20 секунд читает последние запуски GitHub Actions. Пока облачный job работает, видны
его реальные шаги: checkout, установка, анализ, публикация. **Внутренний счётчик частей DeepSeek
во время облачного запуска пока не передаётся**. После завершения скачивается assessment artifact,
и отчёт появляется в истории. Это локальная панель мониторинга, не публичный размещённый сайт.
Закрытие браузера не прерывает GitHub job; остановка локального сервера прекращает только мониторинг.

GitHub-токен не передаётся браузеру или по URL подписанного artifact download. Импорт разрешает
только известные имена файлов, ограничивает объём архива, проверяет схему отчёта и не исполняет HTML
из GitHub. Все исходники и выводы модели в интерфейсе вставляются как текст.

## Переносимый интерфейс

Каждый завершённый `scan` и CI job создаёт `dashboard.html`. Скачайте и распакуйте artifact,
затем откройте HTML в браузере. Он содержит результат, CSS и JavaScript, не требует сервера,
не делает API-запросов. Исходные JSON/Markdown лежат рядом. Отдельная генерация:

```powershell
.venv/Scripts/python.exe -m kmg_agent dashboard-export --output reports/ИМЯ-ЗАПУСКА
```

## Предложения исправлений

Во вкладке «Предложение исправлений» выбирается одна основная находка. Кнопка сообщает, что
запрос платный, и требует явного подтверждения. Сервер проверяет Origin, Host и CSRF-token;
одновременно готовится только одно предложение. Запрос отправляется в официальный DeepSeek API.

CLI-эквивалент:

```powershell
.venv/Scripts/python.exe -m kmg_agent propose --repo targets/KMG-Digital-Hackathon --report reports/ИМЯ-ЗАПУСКА/report.json --finding ID-НАХОДКИ --output reports/patch-01 --env-file .env
```

До запроса проверяются совпадение коммита, контрольной суммы и чистота checkout. Используется
ограниченный контекст выбранной находки и общих компонентов. После ответа проверяются точные,
непересекающиеся замены в разрешённых файлах и синтаксис Python. Файлы с замаскированными значениями
не редактируются. Изменять workflows, создавать новые файлы или выполнять команды модели нельзя.

Результат: `proposal.json` с объяснением, рисками, рекомендуемыми проверками и расходом токенов,
плюс `proposal.patch` с diff. Состояние `needs_decision` означает, что безопасные изменения не
предложены. **Тесты и повторный аудит патча не выполняются, исходный проект не изменяется, commit,
push и PR не создаются.** Патч требует проверки человеком. Это сохраняет ограничения ТЗ 4.1.5 и 5.7.
