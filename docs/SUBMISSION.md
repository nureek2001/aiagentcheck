# Комплект сдачи

Актуальный результат, SHA, ресурсы и ограничения: [OFFICIAL_RUN.md](OFFICIAL_RUN.md).
Ранние LIVE_RUN, GITHUB_RUN и IMPROVEMENTS_VALIDATION сохранены как история.

## Состав

1. Репозиторий решения: https://github.com/nureek2001/aiagentcheck — исходники, промпты,
каталог ИБ, JSON Schema, workflow и README с воспроизводимыми командами.
2. assessment/report.json и report.md — результат оригинального target.
3. assessment/github-job.log — настоящий журнал задания GitHub, execution.log — журнал агента.
4. approach.pdf — описание архитектуры и ограничений на двух страницах.
5. assessment/metrics.json, budget.json и ci-evidence.json — ресурсы и подтверждение CI.
6. TARGET_COMMIT.txt — SHA официального тестового проекта.
7. merge-protection.json — подтверждение защиты main демонстрационного продукта.
8. source/ — снимок исходников и документации; .env, .git и .venv исключены.

Ключ DeepSeek предоставляется отдельно через окружение или GitHub Secrets.
Никаких ключей доступа в комплект включать не нужно.

## Повторение

В Actions репозитория агента выбрать Security assessment → Run workflow и указать
целевой SHA из TARGET_COMMIT.txt. Это отдельный платный прогон с лимитом 12 млн токенов
и 300 попыток; не запускать ради просмотра готового отчёта.
CLI и установка описаны в README. Версия агента, реально использованная в отчёте,
указана в OFFICIAL_RUN.md; последующие коммиты документации не подменяют эту версию.

Сдать архив или доступную папку не позднее чем за один час до защиты. Отсутствующие
материалы обозначить прямо. Неполный аудит не считать завершённой проверкой.
